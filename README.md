# 寵物美容丙級＋寵物急救刷題 PWA v15.2

這是一個可直接部署的完整版本。請整包上傳，不需要再拿 v14.1 的檔案手動合併。

## 保留不動
- `data/professional-13900.json`：原 647 題專業題庫，題目與 ID 不變。
- `data/common-90006-90009.json`：老師版共同科目 399 題有效題，內容不變。
- `data/firstaid-practice.json`：原急救題庫，內容不變。
- 原本 `assets/` 題目圖片與 icon 全部保留。

> 上述檔案內容沒改，所以檔案日期看起來仍可能是 v14.1 時期；這不是漏檔，也不需要另找舊版補進來。

## v15.2 新增／修改
- 共同科目取消每日固定 10 題上限；第一輪持續優先出未做過的題目，自己決定何時停止。
- 首頁顯示共同科目剩餘未做題、距離 11/8、完成第一輪所需平均每日題數。
- 共同科目錯題跨日累積；停止後可選擇立刻進入錯題複習。
- 新增 `data/animal-study.json`：只整理 13900 題庫實際出現的產地、胸型、步態／步伐，不額外補百科知識。
- 動物速查依產地分組，並用「犬類」「鼠類／其他」小標分開；顯示名稱、照片、題庫提及次數。
- 新增圖片小測驗：同一動物若題庫同時考多個屬性，會在同一畫面逐項作答；成績不混入正式 647 題統計。
- 修正 v15.0 `index.html` 的 JS 版本參數錯誤（`v=14.1`），避免更新後仍抓到舊快取。
- Service Worker 對共同題庫 404 會優先回退既有快取；不再因單次 404 直接讓已快取題庫失效。

## 動物照片
照片使用固定 Wikimedia 圖片網址，不再每次呼叫 Wikipedia API 查網址。第一次成功載入後，Service Worker 會把照片快取到裝置；某張照片失敗只影響那張圖，不會影響題庫與刷題。

## 部署
將 ZIP 解壓後的**所有檔案與資料夾**一起上傳到 GitHub Pages 專案根目錄。不要只換 JS，也不要刪除 `data/` 或 `assets/`。
