# 寵物美容丙級｜私人補習班 PWA

針對台灣技術士技能檢定 13900 寵物美容丙級設計的手機刷題 PWA。

## 已完成的功能

- 每日作業：預設專業新題 50 + 共同科目 10 + 到期複習
- 647 題專業題庫匯入／更新
- 4 科共同科目同步（職安、工作倫理、環保、節能減碳）
- 錯題本、今日檢討、到期複習
- 「這題我是猜的」標記，猜對也會再排複習
- 間隔複習與熟練度
- 分類練習、未作答、隨機題、收藏、搜尋
- 80 題／100 分鐘正式模考：64 專業 + 16 共同（4 科各 4）
- 模考成績、分類弱點、題庫覆蓋率
- 歷屆真題同步：目前收錄 113-3、110-3；保留原始題序，並用本機題庫比對答案後才能計分
- 歷屆錯題會回流到同一題的錯題本與間隔複習，另保存歷屆成績
- PWA 安裝、Service Worker、離線使用（題庫完成同步後）
- 本機 IndexedDB 保存進度
- 學習紀錄 JSON 匯出／匯入

## 題庫同步

第一次使用請開啟「同步題庫」。

1. 「自動同步完整題庫」會嘗試取得 13900 公開題庫 PDF，解析 647 題，並同步 4 科共同題庫。
2. 若來源站阻擋跨網域下載，請直接下載 13900 題庫 PDF，再選「匯入 13900 官方／公開題庫 PDF」。PDF 僅在瀏覽器本機解析，不會上傳。
3. 共同科目來源為公開 GitHub 題庫專案內保存的官方 PDF 版本，App 會實際計算解析題數，不把題數硬寫死。

## 安裝／部署

PWA 的 Service Worker 需要 HTTPS（或 localhost），不能直接用 `file://` 雙擊 index.html 完整測試。

最簡單方式：把整個資料夾放到任何支援 HTTPS 的靜態網站空間，例如 GitHub Pages、Cloudflare Pages、Netlify。

本機測試：

```bash
python -m http.server 8080
```

然後開啟 `http://localhost:8080`。

## 資料與版本注意

- 專業 13900 公開鏡像 PDF 顯示版本 109.12.14；目前公開整理仍列 6 個工作項目共 647 題。
- 法規題可能因修法更新，因此 App 特別保留「題庫更新／重新匯入」機制。
- 共同科目版本會隨來源 PDF 更新；同步後以實際解析到的題數為準。
- 歷屆試題保留年份／梯次與原始順序。公開頁面若沒有直接提供答案，App 會把題幹與選項文字和本機題庫比對；只有全部可靠配對後才開放本機計分，避免把錯誤答案寫進學習紀錄。

## 資料保存

題庫與學習紀錄存在瀏覽器 IndexedDB。若清除網站資料，進度也會消失；建議定期在設定頁匯出備份。
